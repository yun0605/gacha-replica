# PRISM — 全息撕卡包网页（Holographic Pack Opener）

一个单文件、零外部请求、原生 HTML / CSS / JS 实现的「潮玩卡牌 + 光学玻璃」风格全息撕卡包互动网页。全部卡面立绘、全息底纹、96 段锯齿撕裂、彩虹光柱粒子与 Web Audio 音效均由代码实时生成，无需联网、无需构建，双击 `index.html` 或用任意本地静态服务器打开即可游玩。

---

## 玩法说明

1. **摇包验包**
   - 桌面端：在卡包正面左右快速晃动鼠标。
   - 移动端：按住卡包主体左右拖动摇晃。
   - 触发「验包感应」后，顶部封口会透出**本包最高稀有度对应颜色的光晕**，包身微微震动，底部显示气息提示（普通：`平平无奇气息` / HOLO：`全息流光气息` / ULTRA：`欧皇气息` / SECRET：`欧皇全闪气息`）。
2. **撕包**
   - 按住卡包顶部 **SEAL** 撕口条横向拖动（默认从左向右，也可从右侧边缘向左拉）。
   - 撕口按 96 段锯齿逐段撕裂，撕开的金属箔条会向上翻卷剥离并透出包内光芒。
   - **中途回弹**：撕到一半松手（未达 88% 阈值）会触发弹性回弹合上。
   - **撕穿爆发**：拉穿后触发彩虹光柱爆发、全息粒子四溅与撕箔脆响。
3. **喷卡与翻卡**
   - 5 张卡面从包口扇形喷出落地，默认卡背朝上。
   - 点击单张卡背即可 3D 翻开，或点击底部 **「一键翻开」** 依次翻开全部。
   - 首次收录的新卡右上角会亮起 **NEW** 角标；翻出 `ULTRA RARE` 或 `SECRET RARE`（含 `Astral 逆闪异画`）时触发全屏出货横幅与彩带粒子。
4. **3D 全息检视**
   - 点击任意已翻开的卡（或典藏册中已点亮的卡）进入大图 3D 全息检视层。
   - 移动指针/手指倾斜卡面，可观察流动彩虹折射与光斑；文字区采用独立避让遮罩压暗高光，保证中英文字始终清晰可读。点击任意处关闭。
5. **典藏册、概率公示、舞台与测试模式**
   - 左下角 **「典藏册 X/12」**：查看 12 张卡收集进度（`localStorage` 持久化），支持二次确认清空重置。
   - 左上角 **「概率公示」**：查看五档稀有度概率、高罕保底及逆闪异画规则。
   - 左上角 **「全闪测试：欧皇待命 / 欧皇已装填」**：开启后当前未开包/下一包必为欧皇全闪包（5 张全 HOLO+ 且必含 ULTRA 或 SECRET），撕开后自动卸下。
   - 右上角：**「白昼展台 / 暗房舞台」** 一键切换与 **「音效开 / 已静音」** 开关。

## 如何替换 / 新增卡面

所有卡池数据、稀有度档位与抽卡规则均集中在 [`index.html`](./index.html) 的 **`PRISM_CONFIG`** 配置对象中（位于 `<script>` 顶部，同时挂载在 `window.PRISM_CONFIG` 方便调试）。

### 1. 修改或新增卡牌数据

在 `index.html` 中找到 `const PRISM_CONFIG = { ... }` 里的 `cards` 数组：

```js
cards: [
  {
    id: "NO.001",              // 卡牌编号（唯一主键，用于 localStorage 存档）
    num: 1,                    // 序号
    en: "Stardust",            // 英文名
    zh: "星尘",                // 中文名
    series: "COSMOS",          // 顶部系列小字
    rarity: "COMMON",          // 稀有度键名：COMMON | RARE | HOLO | ULTRA | SECRET
    artType: "stardust",       // 对应 renderCardArtSVG() 中的立绘分支
    hasAlt: false              // 可选：设为 true 且为 SECRET 时支持逆闪异画变体
  },
  // ... 新增卡牌直接在此追加对象即可
]
```

> 典藏册总数（`X/12`）与编号分母（`NO.00X/012`）会自动读取 `PRISM_CONFIG.cards.length`，新增或删减卡牌后无需手动改 UI 计数。

### 2. 替换或新增立绘美术

在 `index.html` 中找到 `function renderCardArtSVG(card, isAlt = false)`：

- **替换现有卡面立绘**：直接修改对应 `case "stardust":`、`case "astral":` 等分支返回的 SVG 字符串（`viewBox="0 0 240 260"`）。
- **为新增卡牌添加立绘**：在 `switch (type)` 中增加一个与 `card.artType` 同名的 `case`，返回任意内联 `<svg>` 即可（如需保持零外部请求，请勿在 SVG 中引用外链图片或外部字体）。
- **调整稀有度概率与气息文案**：在 `PRISM_CONFIG.rarities` 中修改各档位的 `label`、`stars`、`rate`、`color`、`auraName`，并在 `rollSingleCard()` 中同步调整对应分段阈值即可。

## 本地运行

- 方式一：直接用现代浏览器双击打开 `index.html`。
- 方式二：在当前目录启动任意本地 HTTP 服务，例如：
  ```bash
  python3 -m http.server 8080
  ```
  然后访问 `http://localhost:8080/`。
